# Linux Process Management using C

A university project demonstrating process creation and management in Linux using the C programming language.

## Project Overview

This project explores process creation using `fork()` and demonstrates the relationship between Parent, Child, and Grandchild processes.

## Concepts Covered

- Process creation using `fork()`
- Parent and Child processes
- Grandchild process creation
- Process IDs (PID)
- Arrays, loops, and conditional statements
- Summation of odd numbers
- Counting multiples of 3

## Technologies

- C Programming Language
- Ubuntu Linux
- GCC Compiler
- VirtualBox

## Expected Results

- Sum of odd numbers: `8226671401`
- Number of multiples of 3: `60467`

## Learning Objectives

Understanding Linux process creation, process hierarchy, and basic C programming concepts.
